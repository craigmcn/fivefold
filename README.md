# Fivefold

A forgiving, endless five-letter word game. Words come in stages of ten, with
a harder "boss" word at 5 (×2 points) and a hardest one at 10 (×3). Solving
in one guess scores 60 points, dropping by 10 per guess; after six guesses you
can keep going for no points, or reveal the word and move on. Progress and
stats are saved in `localStorage`.

## Development

```bash
yarn install
yarn dev           # http://localhost:3170
yarn test          # Vitest
yarn test:e2e      # Playwright (run `yarn playwright install` once first)
yarn lint
yarn build
```

## Word lists

`src/data/answers.ts` and `src/data/guesses.ts` are generated by
`scripts/build-words.ts` (`yarn words`) from the raw lists in `scripts/data/`:

| File                 | Purpose                                                       |
| -------------------- | ------------------------------------------------------------- |
| `answers.txt`        | NYT Wordle answer list (the answer pool)                      |
| `allowed.txt`        | NYT extra valid guesses                                       |
| `blocklist.txt`      | Profanity/slurs: rejected as guesses, never answers           |
| `answer-exclude.txt` | Valid guesses that should never be answers                    |
| `zipf.tsv`           | Word frequency per answer (familiarity signal for difficulty) |

`zipf.tsv` comes from Python's [`wordfreq`](https://pypi.org/project/wordfreq/).
If `answers.txt` changes, regenerate it before running `yarn words`:

```bash
python3 -m venv .venv && .venv/bin/pip install wordfreq
.venv/bin/python -c "
from wordfreq import zipf_frequency as z
for w in sorted(set(open('scripts/data/answers.txt').read().split())):
    print(f'{w}\t{z(w, \"en\"):.2f}')
" > scripts/data/zipf.tsv
```
